# Portail Bedrock releases

Android APK releases of **Portail Bedrock**, a free app that makes any Minecraft Bedrock server appear in the LAN tab of a PlayStation, Switch or Xbox. Free, no ads, no account, no tracking.

This repository only hosts the APK files and the `latest.json` file the app reads to offer updates. The source code is not here.

- Download page: https://zenkyr.itch.io/portail-bedrock
- Help and feedback: https://discord.gg/gTukR24g78

---

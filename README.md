# Portail Bedrock

**Join any Minecraft Bedrock server from your PlayStation, Switch or Xbox.** Your Android phone makes the server appear in the console's Worlds tab like a local game, then sends the console to the real server. Free, no ads, no account, no tracking.

## ⬇️ Download

**[Download the latest APK](https://github.com/ZenkyR/portail-bedrock-releases/releases/latest/download/portail-bedrock.apk)** (Android 8.0 or newer)

1. Open the file on your Android phone.
2. If Android asks, allow your browser to install apps.
3. Add your server, tap Start, and join it from your console's Worlds tab (same Wi-Fi as your phone).

The app tells you when a new version is out. All versions and their notes: [Releases](https://github.com/ZenkyR/portail-bedrock-releases/releases).
